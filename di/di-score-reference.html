Score Reference

Five shared scores translate millions of raw signals into a handful of numbers every agent can reason about. They are computed once and read everywhere.

How every score works

Each score runs 0–100 and is built the same way: positive and negative signals from Account 360, weighted into a single number. A score is an opinion, not a fact — a way to rank attention, not a verdict.

They start as heuristics (defensible base rates and rules, no ML required) so the platform is useful on day one. As the Outcome Store fills, the learning loop retunes the weights — so the scores get sharper without re-architecting anything.
