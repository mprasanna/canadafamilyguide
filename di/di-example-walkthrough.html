3 Scores — the system forms an opinion → Score reference

No human can read millions of Account 360 profiles. The platform distils each one into five 0–100 scores — computed once, read by every agent. A score is an opinion, not a verdict.

What scores do: they gate decisions. Expansion score 25 means the Bundle Agent will not even submit a cross-sell recommendation — the score prevents it before the NBA Engine is reached. Churn score 78 means the Policy Engine is pre-armed to block any expansion offer that gets through.

5 NBA Engine — one number decides → NBA page

The NBA Engine receives four recommendations and reduces each to a single number — Expected Value — then ranks them. The highest EV that survives policy wins. For ABC Corp, that is Recovery.

NBA decision · ABC Corp
Recovery Agent wins · Expected Value $20,395
Recovery: $20,395 ← #1 Cancellation: $9,980 ← fallback Renewal: contingent Bundle: $300 → blocked by policy
Recovery wins because both routes target the same $24,000 — the engine takes the cheaper, higher-probability path first and holds the monthly-plan offer as a fallback.
The full calculation — probability inputs, ARR weighting, cost comparison, and the step-by-step ranking logic — is on the NBA Engine page → This walkthrough shows the outcome. That page shows the mechanism.
6 Policy, Capacity & Budget — guardrails → Architecture story

Expected Value proposes. Policy disposes. Hard business rules remove any action regardless of rank. Capacity ensures we only create as many tasks as humans can action. Communication Budget means one well-chosen touch, not five.

PASSRetry payment — no discount, no concession. No policy rule applies. Cleared.
BLOCKBundle / Zoho One cross-sell — policy forbids expansion to at-risk accounts (open payment failure + churn 78). Removed regardless of EV.
PASSMonthly-plan fallback — within the discount cap and one-save-offer-per-year limit. Allowed, but only if recovery fails.
SLOTCapacity: at $24,000 with 85% recoverability, ABC Corp ranks inside today's AM slots. A task is created. A $300 account would not qualify.
1 of 1Communication budget: one touch this cycle. The renewal reminder and any marketing mail are suppressed so they don't pile on.

The point of surfaces: the intelligence is in one place — the NBA decision. Surfaces are just renderers. Adding a new surface (a mobile app, a partner portal) does not change the decision logic — it just adds a new way to see the same thing.

The holdout: a small group of similar accounts receives no intervention. The difference in retention rate between the treated group and the holdout is the platform's true, causal impact — not correlation, but proof that the action caused the result. This is what separates a decision platform from a dashboard.
The whole platform in one line
Sources → 360 → Scores → Agents → NBA → Policy → Action → Surfaces → Outcome → back to Scores
ABC Corp is one account. This loop runs on every account, every day, in parallel — across Recovery, Cancellation, Renewal, Churn Prevention, Expansion, and every other agent in the catalog. The platform does not scale by adding people. It scales because the loop is the same regardless of how many accounts are in it.
